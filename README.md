# 365 Days of Code 🚀

A personal one-year coding journey focused on becoming a stronger and more versatile programmer through consistent daily practice.

## 🎯 Goal

The goal of this challenge is simple:

> Code every day for 365 consecutive days.

I will spend approximately 1–2 hours programming each day. The focus is not on learning something completely new every day, but on building a consistent habit, strengthening my fundamentals, solving problems, building projects, and continuously improving my programming skills.

## 🗺️ Learning Path

The journey will gradually cover:

- 🐍 Python
- 🧠 Algorithms & Data Structures
- 💻 Software Engineering
- 📊 Data Analysis
- 🗄️ SQL & Databases
- 🌐 Backend Development
- 🐳 Docker & Development Tools
- 🤖 Machine Learning
- 🧠 Artificial Intelligence

The roadmap is flexible and may evolve as my skills and interests develop.

## 📅 Daily Structure

Each day may include:

1. Theory and learning
2. Practical coding exercises
3. Problem-solving challenges
4. Review of previous topics
5. Optional bonus challenges

The difficulty will gradually increase throughout the year.

## 🏆 Rules

- Code every day.
- Aim for approximately 1–2 hours per day.
- Focus on consistency rather than perfection.
- Try to solve problems independently before asking for help.
- Do not blindly copy solutions.
- Review mistakes and understand why they happened.
- Commit my progress regularly to GitHub.
- Gradually increase the difficulty.
- Build projects instead of only completing exercises.

## 📊 Progress Tracking

Throughout the challenge I will track:

- Days completed
- Time spent coding
- Topics studied
- Problems solved
- Projects completed
- Difficulties and mistakes
- Major milestones

## 🎓 Starting Point

This challenge begins with an existing foundation in programming and gradually moves toward more advanced Python, software engineering, data analysis, backend development, machine learning, and AI.

The purpose of this repository is not to prove that I can code every day perfectly.

It is to document the process of becoming a better programmer.
